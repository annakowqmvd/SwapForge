# SwapForge

SwapForge is a cloud-native, distributed platform engine that leverages auto-scaling and dynamic resource allocation.

The key benefits of using SwapForge include:

- SwapForge is a cloud-native, distributed
- platform engine that leverages auto-scaling
- and dynamic resource allocation

## Key Features

- SwapForge is a cloud-native, distributed

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/SwapForge.git`
2. `cd SwapForge`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SwapForge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
